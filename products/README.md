# Products

Products are optional surfaces installed after a Xian chain exists. They are
not genesis contracts, and they are not shipped in node images.

Each product entry points to:

- the owning product repository
- any pinned contract packs in this repo
- related examples
- app or service components owned by product repos
- an explicit post-genesis lifecycle declaration

This keeps core chain assets separate from application/protocol products while
still giving operators one catalog to inspect.
